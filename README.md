This script reduces bid discovery time by 90% by automating how HLA bid pulls are logged, formatted, and shared. It opens the active spreadsheet and targets three tabs: Daily Pull HLA (raw import), Seen HLA (running log), and New Bids HLA (fresh uniques). It reads the daily data, verifies the required headers—Project_Name_URL, Project_Name, and Bid_Information—and exits if there’s no body data. It builds a case-insensitive set of already-seen project names from Seen HLA, then filters the daily rows to keep only projects not yet recorded. For each new row, it parses Bid_Information into Date and Time by splitting on " - ", and converts Project_Name into a clickable hyperlink using Project_Name_URL. It writes standardized headers (Project_Name, Date, Time) to Seen HLA and appends the newly formatted rows. It then clears New Bids HLA, rewrites the same headers, and fills it with just the newly discovered projects. Next, it assembles a concise HTML email: a count of new bids as of today and, for each bid, the linked project name plus date and time. The email is sent to the specified recipients, and finally the script clears Daily Pull HLA to reset the staging sheet for the next import.
